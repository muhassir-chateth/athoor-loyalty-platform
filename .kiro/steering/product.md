# Product Overview

This workspace connects the **Athoor London** Shopify store (`myathoorlondon.myshopify.com`) to AI assistants via the Model Context Protocol (MCP).

The primary purpose is to enable AI-driven management of the Shopify store — products, customers, and orders — through natural language interactions in the Kiro IDE.

There is no custom application code. The workspace acts as a configuration and runtime environment for the `shopify-mcp` package, which wraps Shopify's GraphQL Admin API as MCP tools.
